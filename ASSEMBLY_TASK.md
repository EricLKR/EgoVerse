# Assembly Task branch

This branch archives the training and deployment code for the single-frame,
three-camera PIPER + human HPT **Absolute-Reference V3** experiment used on
Assembly Task New1.

Start here:

- [`projects/assembly_task_hpt_absolute_reference_v3/README.md`](projects/assembly_task_hpt_absolute_reference_v3/README.md)

The branch intentionally excludes datasets, checkpoints, robot logs and replay
arrays. The expected 30k checkpoint filename and SHA-256 are recorded in the
project README.
